## Context

StudyTrack 的公開首頁、帳號頁與學習頁目前各自包含內嵌 CSS 與 Tailwind 任意色彩類別。首頁已經採用新的手帳式版面，但仍混用粉紅與鼠尾草綠；帳號與學習頁則使用舊的粉紫與粉紅。專案沒有共用的頁面基底模板或主題樣式檔，若只逐頁替換字面色碼，後續會再次產生漂移。

這是純視覺重整：路由、資料、表單、文字與互動行為維持不變。建立共用色彩權杖可讓所有學生與訪客頁面從同一來源取得色彩值。

## Goals / Non-Goals

**Goals:**

- 讓首頁、帳號頁與學習頁以明亮莫蘭迪紫白呈現一致的背景、卡片、按鈕、文字、邊框與鍵盤焦點。
- 讓同一個語意用途在所有使用者頁面使用相同色彩權杖。
- 維持文字、按鈕、輸入框與焦點狀態的可讀性和可辨識性。

**Non-Goals:**

- 不變更 Django `/admin/`、帳號或學習功能、資料庫、URL、表單欄位、AI 助教或圖表。
- 不導入 CSS 框架、設計系統、外部字型或第三方資產。
- 不變更既有頁面的版面結構與文案。

## Decisions

### Shared semantic color tokens

在專案靜態資源中建立單一主題樣式檔，定義 `--page-bg`、`--surface`、`--surface-subtle`、`--primary-surface`、`--primary-surface-hover`、`--border`、`--text`、`--text-muted` 與 `--focus` 等語意色彩權杖。每個使用者模板以 Django static 標籤載入此檔案，並以權杖取代可預期的色彩用途。

這比為九個模板各自複製 `:root` 色碼更容易維護。保留模板內只屬於版面與元件的 CSS，避免本次重構整個前端架構。

### Bright Morandi purple-white palette

權杖採用使用者確認的色票：背景 `#FCFBFF`、卡片 `#FFFFFF`、淺霧紫 `#F4F0F8`、主要按鈕 `#E7DCEF`、按鈕懸停 `#DCCCE8`、邊框 `#E8E0EE`、深文字 `#453C4D`、次要文字 `#746B7C`、焦點 `#A98DBC`。錯誤訊息可保留低飽和暗紅，因為它表示錯誤狀態而非品牌分類。

不沿用首頁現有粉紅與鼠尾草綠，讓視覺身份集中在紫白；也不以淺紫作為內文文字，確保明亮背景上仍有足夠對比。

### Scoped student-facing templates

這次只修改公開首頁、登入、註冊、登出、課程列表、課程詳情、建立課程、建立錯題與課程設定。Django `/admin/` 是框架的管理後台，未納入學生產品的視覺承諾。

## Implementation Contract

使用者在任何納入範圍的頁面 SHALL 看見相同的霧白背景、白色表面、淺霧紫區塊、柔亮紫主要按鈕、墨紫主文字與灰紫次要文字。按鈕懸停與鍵盤焦點 SHALL 使用定義的主題權杖；錯誤文字維持明確的錯誤色。

每個納入範圍的模板 SHALL 載入共用主題檔案。實作不得修改 URL 名稱、表單欄位名稱、提交方法、登入狀態條件或連結目的地。Django `/admin/` 不在範圍中。

驗收時，以未登入與已登入頁面手動檢查色彩一致性、鍵盤焦點與可讀性；執行 `uv run python manage.py test` 確認既有路由與表單測試維持通過；以模板內容檢查確認納入範圍的頁面都引用共用主題檔且不保留被取代的粉紅／綠色品牌色。

能力層級的可觀察行為不變；本變更僅調整既有介面的視覺呈現。

## Risks / Trade-offs

- [Tailwind 任意色彩類別繞過共用權杖] -> 在變更後對九個模板搜尋舊色碼與主題引用，並以瀏覽器檢查每種頁面類型。
- [過淺的紫色降低可讀性] -> 主文字和互動標籤固定使用深文字權杖，淺紫只用於表面、按鈕底色與區塊。
- [錯誤狀態被品牌色覆蓋] -> 保留錯誤文字的暗紅語意例外，並不把它納入一般色票替換。

## Migration Plan

1. 加入共用靜態主題檔並先讓所有目標模板載入。
2. 依模板群組替換品牌用途色彩，維持每次變更後頁面可渲染。
3. 執行自動測試與跨頁手動檢查；若出現可讀性或樣式回歸，先將該模板恢復為最近的可用版本，再調整權杖對應。
